# Security Policy

## Supported versions

This module has one tagged release, `v0.1.0`, and active development on
`main`. Security fixes are made against `main` and released as a new tag;
there is no long-term support branch to backport to.

## Reporting a vulnerability

Gap: this repository does not yet have GitHub private vulnerability
reporting enabled (checked via the repository's private vulnerability
reporting setting), so there is currently no private channel configured for
reporting a suspected vulnerability. Do not open a public GitHub issue for a
suspected vulnerability while this gap stands, since that discloses it
before a fix exists.

A maintainer needs to either enable private vulnerability reporting for this
repository (repository Settings, Security, "Private vulnerability
reporting") or designate an alternate private contact, and update this file
once one of those is in place.
